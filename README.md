# 🎓 Student Performance Analytics System

## 📌 Project Overview
The Student Performance Analytics System is a data analytics project that analyzes student academic performance to identify the key factors influencing grades, attendance, and placement status. The project follows the complete data analytics workflow, from data cleaning to dashboard creation.

---

## 🎯 Objective
- Analyze student academic performance.
- Identify factors affecting final marks.
- Study the impact of attendance, study hours, and internet access.
- Analyze placement trends.
- Build an interactive Power BI dashboard for decision-making.

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
- Jupyter Notebook

---

## 📂 Dataset
The dataset contains:
- Student Name
- Attendance %
- Internal Marks
- Final Marks
- Assignment Scores
- Study Hours
- Extra Activities
- Family Income
- Internet Access
- Placement Status

---

## 🧹 Data Cleaning
- Removed duplicate records.
- Handled missing values.
- Corrected invalid marks.
- Standardized data types.
- Fixed inconsistent values.

---

## 📊 Exploratory Data Analysis (EDA)
Performed analysis on:
- Attendance vs Final Marks
- Study Hours vs Final Marks
- Internet Access vs Academic Performance
- Extra Activities vs Final Marks
- Correlation between numerical features
- Student Performance Distribution

---

## ⚙️ Feature Engineering
Created new features:
- Average Score
- Performance Level
- Risk Category

---

## 📈 Power BI Dashboard
Dashboard includes:
- Total Students (KPI)
- Average Final Marks (KPI)
- Average Attendance (KPI)
- Placement Rate (KPI)
- Students by Performance Level
- Study Hours vs Final Marks
- Placement Status Distribution
- Average Final Marks by Internet Access
- Average Final Marks by Extra Activities
- Placement Rate by Performance Level

---

## 💡 Key Insights
- Students with higher study hours generally achieved better final marks.
- Students with internet access scored slightly higher on average.
- Excellent-performing students had the highest placement rate.
- Attendance showed a positive relationship with academic performance.
