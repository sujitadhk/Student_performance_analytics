# Student_performance_analytics
Project Overview

This project analyzes student academic performance using Python and Power BI to identify the factors affecting student success and placement.

The project demonstrates a complete Data Analytics workflow including:

Data Cleaning
Exploratory Data Analysis (EDA)
Feature Engineering
Dashboard Development
Business Insights


Objective

Analyze student performance and answer questions like:

Does attendance affect marks?
Does study time improve grades?
Does internet access improve academic performance?
Which students are at risk?
How does performance affect placement?

Students studying more hours generally scored higher.
Excellent performers had the highest placement rate.
Internet access showed a positive impact on final marks.
Attendance strongly correlated with academic performance.
